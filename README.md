# Treatly

A desktop pet for macOS that turns your todos into treats and nags you until you finish them.

**Website:** https://tailamphat.github.io/treatly/

Your pet (a dog, a cat, a panda, a mighty gorilla...) roams the bottom of your screen. Each task from **Apple Reminders** is a treat in its bowl. The pet fetches the most urgent one and carries it around. Ignore it and the pet escalates: it drops the treat in front of you, then yells, then whines. Nagging comes in bursts with roaming breaks in between, and every animal has its own walk speed, energy, sleepiness and patience. Mark the task done and it eats the treat.

## Install

```sh
brew install --cask tailamphat/tap/treatly
```

Or download `Treatly-<version>.zip` from [Releases](https://github.com/tailamphat/treatly/releases), unzip and move Treatly to Applications. Requires macOS 14 (Sonoma) or later. Releases aren't notarized yet: the first time, open System Settings > Privacy & Security and click **Open Anyway**.

## Build and run

Requires macOS 14+ and the Swift toolchain (Command Line Tools are enough).

```sh
./scripts/bundle.sh --open     # builds build/Treatly.app and launches it
./scripts/release.sh           # universal release zip + Homebrew cask (docs/releasing.md)
swift run TreatlyChecks        # runs the core logic checks
```

The app lives in the menu bar (paw icon). It needs a real `.app` bundle for the Reminders permission prompt, so use the script rather than `swift run Treatly`.

## Using it

- **Click the pet**: Done (it eats the treat and completes the task), Snooze 10 min / 1 hour (it buries the treat), Next treat.
- **Drag the pet** anywhere; it falls back to the ground.
- **Click a bowl** to see that source's tasks and pick which one the pet should go after.
- **Bowl**: pick Classic, Steel, Ceramic, Puppy or Country Tub in Settings or the menu.
- **Poop**: after eating, the pet leaves a poop for 10 to 15 seconds. Pick Cute, Classic, Golden or Rainbow in Settings, or turn it off.
- **Wardrobe**: dress the pet in a party hat, bow, crown, bandana, sunglasses, a flower or headphones (Settings or the menu).
- **Music**: when a music or video app is playing, the pet sits down, puts its headphones on and bobs along.
- **Menu bar**: choose the pet, rename it, pick lists, set how fast nagging escalates, turn on sound.

## Art

All art is generated by `scripts/art/chibi.py` (MIT, no dependencies): the pets as tiny chibi pixel sprites, their wardrobe, the bowls, the banana trees, the bamboo pot, the treats and the poop. Run `python3 scripts/art/chibi.py --preview` to regenerate everything and write `build/chibi-preview.png`.

For screenshots and development, `open --env TREATLY_DEMO=1 build/Treatly.app` adds a few fake tasks.

## Make your own pet

Pets are plain JSON with text pixel art. See [docs/pet-packs.md](docs/pet-packs.md). Drop a pack into the folder that the **Pets Folder** button in Settings opens.

## Project layout

- `Sources/TreatlyCore` - pure logic: task selection, escalation, pet behaviour, pet packs
- `Sources/Treatly` - the AppKit app: windows, rendering, menu bar, the Reminders source
- `Sources/TreatlyChecks` - assertion runner for the core (Command Line Tools ship without a working XCTest)
- `Pets/` - bundled pet packs
- `docs/PLAN.md` - concept, scope and roadmap
- `site/` - the website, published to GitHub Pages by `.github/workflows/pages.yml` (preview with `./scripts/site.sh` and serve `build/site`)
