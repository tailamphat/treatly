# Treatly

A desktop pet for macOS that turns your todos into treats and nags you until you finish them.

Your pet (a dog, a cat, King Kong...) roams the bottom of your screen. Each task from **Apple Reminders** or **Google Tasks** is a treat in that source's bowl. The pet fetches the most urgent one and carries it around. Ignore it and the pet escalates: it drops the treat in front of you, then yells, then whines. Nagging comes in bursts with roaming breaks in between, and every animal has its own walk speed, energy, sleepiness and patience. Mark the task done and it eats the treat.

| Pet | Treat | Personality |
|---|---|---|
| Shiba Inu | bone | sassy, dramatic screamer |
| Golden Retriever | bone | patient, hopeful |
| Chihuahua | bone | tiny, yappy, runs everywhere |
| Orange Tabby | fish | chaotic, random zoomies |
| Black Cat | fish | sleepy, silent and mysterious |
| King Kong | banana | KONG SMASH |

## Build and run

Requires macOS 14+ and the Swift toolchain (Command Line Tools are enough).

```sh
./scripts/bundle.sh --open     # builds build/Treatly.app and launches it
swift run TreatlyChecks        # runs the core logic checks
```

The app lives in the menu bar (paw icon). It needs a real `.app` bundle for the Reminders permission prompt, so use the script rather than `swift run Treatly`.

## Using it

- **Click the pet**: Done (it eats the treat and completes the task), Snooze 10 min / 1 hour (it buries the treat), Next treat.
- **Drag the pet** anywhere; it falls back to the ground.
- **Click a bowl** to see that source's tasks and pick which one the pet should go after.
- **Menu bar**: choose the pet, rename it, pick lists, set how fast nagging escalates, turn on sound.

Google Tasks needs a one-time setup with your own OAuth client: see [docs/google-tasks.md](docs/google-tasks.md).

## Art

King Kong, the bowls, the banana trees and the treats are generated by `scripts/art/generate.py` (MIT, part of this repo). Run `python3 scripts/art/generate.py --preview` to regenerate them and write `build/art-preview.png`.

For screenshots and development, `open --env TREATLY_DEMO=1 build/Treatly.app` adds a few fake tasks.

## Make your own pet

Pets are plain JSON with text pixel art. See [docs/pet-packs.md](docs/pet-packs.md). Drop a pack into the folder that **Open Pets Folder** opens.

## Project layout

- `Sources/TreatlyCore` - pure logic: task selection, escalation, pet behaviour, pet packs, OAuth helpers
- `Sources/Treatly` - the AppKit app: windows, rendering, menu bar, Reminders and Google Tasks sources
- `Sources/TreatlyChecks` - assertion runner for the core (Command Line Tools ship without a working XCTest)
- `Pets/` - bundled pet packs
- `docs/PLAN.md` - concept, scope and roadmap
